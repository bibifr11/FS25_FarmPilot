## Other mods FarmPilot works with (no code included)

FarmPilot can work together with Courseplay (https://github.com/Courseplay/Courseplay_FS25, GPLv3) and a few other mods
(for example FS25_autoTurnOffTurnLights). It only detects them in game and calls their public functions at runtime,
like any compatibility code. No source code, texture or other file from Courseplay or from these mods is included in FarmPilot.
Courseplay must be downloaded separately from its own authors.
